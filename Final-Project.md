# Omnifood

Omnifood is a responsive food subscription website built as the final project of the course. The project combines everything learned throughout the course, including responsive web design using media queries.

The website presents a fictional AI-powered food delivery company that creates personalized meal plans based on users’ dietary preferences and delivers healthy meals daily.

## Features

* Fully responsive web design
* Modern landing page structure
* Responsive navigation
* Pricing section
* Testimonials and gallery
* Call-to-action section
* Mobile-friendly layout using media queries

## Technologies Used

* HTML5
* CSS3
* JavaScript
